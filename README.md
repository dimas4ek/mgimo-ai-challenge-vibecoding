# Цифровой деканат AI High School

Личный кабинет студента, где в одном месте собраны расписание, оценки, справки и объявления деканата. Работает с телефона от 360 px. Прототип для MGIMO AI Challenge, номинация «Вайб-кодинг».

> **Это концепт для конкурса, а не официальный сервис.** Вуз AI High School (Высшая Школа ИИ), его факультеты, преподаватели, студенты и оценки вымышлены.

**Демо:** [aihighschool.me](https://aihighschool.me) — работает на виртуальной машине в Yandex Cloud.

| `staff`    | `aihs-staff-2026`    | Вероника Сташевская, сотрудник деканата: очередь заявок                         |

Пароли вымышленные, они нужны только для демо. Аккаунты общие для всех. Если кто-то до вас уже подал заявки, сбросьте свои данные: «Профиль» → «Сбросить демо-данные». Сброс трогает только ваш аккаунт.
Демо-данные сами обновляются на новую неделю в ночь на понедельник по Москве; заявки, созданные за прошлую неделю, при этом пропадают.

## Продакшен на Yandex Cloud

Демо размещено на Ubuntu VM в Yandex Cloud. DNS домена `aihighschool.me` направлен на VM; Docker Compose запускает PostgreSQL, API со статикой сайта и Caddy. Данные PostgreSQL хранятся в именованном volume `pgdata`, поэтому переживают пересоздание контейнера.

На этой VM Caddy использует сертификат Let's Encrypt, выпущенный Certbot через DNS-01: проверка домена выполняется TXT-записью `_acme-challenge`, без входящего запроса к сайту. Сертификат установлен в `/etc/letsencrypt/live/aihighschool.me/` и настроен в Caddy на самой VM. Это локальная настройка текущего сервера: стандартные `deploy/compose.yml` и `deploy/Caddyfile` в репозитории оставлены с автоматическим HTTPS от Caddy.

Ручной сертификат не обновляется автоматически; действующий сертификат истекает **19 февраля 2027 года**. Чтобы выпустить следующий, на VM повторите:

```sh
sudo certbot certonly --manual --preferred-challenges dns -d aihighschool.me
```

Добавьте в DNS Namecheap TXT-запись с именем `_acme-challenge` и значением, которое покажет Certbot. Дождитесь появления значения в публичном DNS и продолжите Certbot. После выпуска перезапустите только контейнер Caddy, чтобы он загрузил новый сертификат:

```sh
sudo docker compose --env-file .env -f deploy/compose.yml up -d --force-recreate caddy
```

Не удаляйте старую TXT-запись до успешной проверки Certbot и не добавляйте полученное значение в репозиторий.

## Что попробовать за 2 минуты

1. Войдите как `student`. На главной будут следующая пара, дедлайны и объявления деканата.
2. «Расписание»: занятия на сегодня и на неделю, переносы, замены и отмены с пояснением.
3. «Успеваемость»: баллы по дисциплинам, сводка «Как у меня дела» и калькулятор «Что нужно набрать» для закрытия сессии или стипендии.
4. «Заявки» → «Новая заявка» → «Выписка с оценками» → «Отправить».
5. Выйдите и войдите как `staff`. Найдите заявку в очереди и нажмите «Готово».
6. Снова войдите как `student`. Придёт уведомление, а в карточке заявки появится «Справка для печати» с QR-кодом. QR открывает публичную страницу проверки, где видны только инициалы.
7. Войдите как `student2`: у него свои данные, и чужие заявки не открыть даже по прямой ссылке.

## Как это устроено

- **Вход.** Логин и пароль. Пароли хранятся только как хеш argon2id. Сессия хранится в базе, браузер получает httpOnly-cookie, поэтому из JavaScript её не прочитать. На попытки входа стоит ограничение по частоте.
- **Доступ к данным.** Студент получает данные только через `/api/me/*`, а сервер берёт id студента из сессии, а не из адреса. На чужую заявку или справку сервер отвечает 404. Кабинет сотрудника для студента закрыт (403).
- **Секреты.** Пароль БД и прочие ключи лежат только в переменных окружения на сервере. В репозитории есть лишь `.env.example` с заглушками.
- **Стек.** TypeScript-монорепо: Zod-контракт (`packages/contract`), API на Hono + Drizzle + PostgreSQL (`apps/api`), SPA на React 19 + Vite + TanStack Query + Tailwind (`apps/web`). Деплой — Docker Compose: API, Postgres и Caddy (`deploy/`).

## Запуск локально

Нужны Node 24+ и pnpm 10 (`npm i -g pnpm@10.34.9`). Docker для разработки не нужен: API работает на встроенном PGlite и при первом запуске сам заполняет базу демо-данными.

```
pnpm install
pnpm dev          # API на :3000, сайт на http://localhost:5173
pnpm test         # автотесты всех пакетов
```

Прод-стек: скопируйте `.env.example` в `.env`, задайте `DOMAIN` и `POSTGRES_PASSWORD`, затем выполните `docker compose --env-file .env -f deploy/compose.yml up -d --build`.
