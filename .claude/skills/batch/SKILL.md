Кто ты — в `CLAUDE.local.md` (`agent:*`); если файла нет — остановись и спроси человека.
Всё нужное — в этом skill и в skills, на которые он ссылается. `docs/AI-COLLAB.md` целиком не читай;
открывай только конкретный раздел, если возникло сомнение.

Если в аргументах есть `parallel` — прочитай §14 и работай по нему. Иначе обычный режим (§8):

Повторяй, пока не сделано 3 задачи:
1. Skill `take-task`. Свободных задач нет → `node .claude/scripts/wait-task.mjs` **в фоне** (Bash с `run_in_background`)
   и жди уведомления о его завершении. Сам доску не опрашивай: скрипт делает это без расхода лимита.
   Код выхода: `0` — задача освободилась, снова `take-task`; `2` — ждать нечего (задач нет или они ждут людей),
   выходи из цикла; `3` — не дождался за 90 мин, выходи из цикла; `1` — `gh` не отвечает, выходи и напиши об этом в отчёте.
   Ожидание не считается задачей пачки.
2. Skill `contract`: ветка, контракт, PR контракта, мерж, `contract-merged`.
3. Реализация и тесты в той же ветке (§5). Команды — только из `CLAUDE.md`.
   В том же PR добавь запись в свой журнал `docs/process/<agent>.md` (формат в `.claude/rules/process-log.md`).
4. Перед PR реализации: `git fetch` и `git rebase --onto origin/main <SHA контракт-PR>` (§5),
   затем `pnpm lint && pnpm typecheck && pnpm test && pnpm build` зелёные.
5. PR реализации (`#N: …`, в описании `Board: dimas4ek/mgimo-ai-challenge-vibecoding-board#N`) и skill `merge-pr` (тип impl).
6. На любом шаге застрял → skill `stuck`, затем следующая итерация.

В конце — отчёт в формате §8 (Сделано / В работе у напарника / Заблокировано / Нужен человек / Дальше).
