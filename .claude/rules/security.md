# Безопасность

Жюри проверит это руками: подставит чужой id в адрес, поищет пароли в коде. **Репозиторий публичный**, поэтому всё, что попало в git, видно всем.

## Доступ только к своим данным
- Студенческие эндпоинты живут только под `/api/me/*`. id студента берётся **из сессии**, никогда из URL, query или body.
- Роутов вида `/api/students/:id` для студентов нет.
- Ресурс с собственным id (заявка, справка, уведомление) выбирается условием `id = ? AND student_id = <из сессии>`. Если строка не нашлась, отвечаем **404**, а не 403: так не раскрываем, что ресурс существует.
- id ресурсов — UUID, а не автоинкремент.
- `/api/staff/*` закрыт middleware `requireRole('staff')`. Студент получает 403.
- Проверка прав делается на сервере. Скрытая кнопка в UI защитой не считается.
- На каждый новый эндпоинт с id пишется тест «чужой пользователь получает 404».

## Пароли и сессии
- Пароли хешируются только argon2id (`@node-rs/argon2`). Открытый пароль нигде не хранится и не логируется.
- Сессия хранится в таблице БД, клиенту уходит cookie `httpOnly; Secure (в проде); SameSite=Lax; Path=/`. Токены в `localStorage` не кладём.
- Logout удаляет сессию на сервере.
- На `/api/auth/login` стоит rate-limit. Ошибка всегда одинаковая: «неверный логин или пароль», без уточнения, что именно неверно.

## Секреты
- Ключи, пароли БД и секреты сессий берутся только из переменных окружения на сервере. В git лежит лишь `.env.example` с заглушками.
- В бандл фронта секреты не попадают. Переменные `VITE_*` публичны, секретов в них быть не может.
- Пароли тестовых аккаунтов вымышленные, они живут в сиде и в README для жюри. Это нормально. Нельзя использовать пароли, которые кто-то из нас применяет где-то ещё.
- Перед коммитом проверь diff: нет `.env`, токенов, приватных ключей.

## Ввод и вывод
- Каждый вход API валидируется Zod-схемой из `contract`.
- SQL строим только через Drizzle с параметрами, без склейки строк.
- В ответе отдаём только поля из DTO контракта. Хеши и внутренние поля наружу не уходят.
- Публичная страница проверки справки (QR) показывает минимум: тип справки, дату, статус «действительна» и инициалы. Без полного ФИО и оценок.
