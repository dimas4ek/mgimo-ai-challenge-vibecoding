# Linux и Windows работают одинаково

Команда разрабатывает на Arch Linux и на Windows. Всё, что работает у одного, должно работать и у другого.

- **Никаких bash-, sh- и PowerShell-скриптов** в рабочем процессе. Скрипты пишем на Node (`scripts/*.ts` или `.mjs`) или кладём в `package.json`. Не используем `rm -rf`, `cp`, `export X=…`, `&&` с env-переменными. Нужно удалить — `node:fs` (`rm({ recursive: true })`). Нужны env — `cross-env` или чтение `.env` в коде.
- Пути строим через `node:path` (`join`, `resolve`), без ручных `/` и `\\`. Для `import.meta` используем `fileURLToPath`.
- Переводы строк только LF, это закреплено в `.gitattributes` и `.editorconfig`. Кодировка UTF-8.
- Регистр в именах файлов и импортах совпадает буква в букву: Windows регистр прощает, Linux и CI нет.
- Нативные модули допустимы только с готовыми бинарниками под win-x64 и linux-x64 (например, `@node-rs/argon2`). Для dev и тестов используем PGlite, Docker и локальный Postgres не нужны.
- Docker нужен только для деплоя, локальная разработка без него.
- Порты и хосты берутся из env с дефолтами. В коде не пишем `localhost` там, где нужен `0.0.0.0` в контейнере.
- Даты и время считаем в `Europe/Moscow` явно, от таймзоны машины не зависим.
- CI гоняет lint, typecheck и test на `ubuntu-latest` и `windows-latest`. Красный Windows-джоб блокирует так же, как красный Linux-джоб.
