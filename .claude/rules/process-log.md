# Журнал работы с ИИ (обязательно)

По журналу жюри оценивает критерий «Масштаб использования нейротехнологий»: качество промптов, работу с ошибками ИИ, наглядность процесса. Из журнала потом собирается итоговый PDF. Если не записать сразу, восстановить позже не получится.

## Куда писать
- У каждого агента свой файл: `docs/process/dimas.md` или `docs/process/evv.md`. В чужой журнал не пишем.
- Чей журнал, определяй по человеку, который ведёт сессию. Если неясно, спроси.
- Скриншоты кладём в `docs/process/screenshots/` с именем `YYYY-MM-DD_<агент>_<что>.png`.

## Когда писать
После каждой законченной задачи или заметного шага, а также когда ИИ ошибся и ошибку пришлось исправлять.

## Формат записи
```md
### YYYY-MM-DD HH:MM — <короткое название задачи>
**Этап / модуль:** этап 1 / api
**Задача:** что нужно было сделать и зачем.
**Ключевой промпт:** > дословно главный промпт человека (можно сокращать, без секретов)
**Что сделал ИИ:** 2–4 строки по существу, какие файлы.
**Ошибки ИИ и исправление:** что пошло не так, как заметили, как исправили (или «нет»).
**Вручную:** что человек сделал руками (или «ничего»).
**Скриншот:** screenshots/… (если есть UI)
```

## Чего не писать
Секреты, токены и пароли (кроме вымышленных тестовых аккаунтов), реальные персональные данные, длинные логи. Только суть.
